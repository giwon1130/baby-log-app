## 심사 메모 (App Review Information)

- [ ] 테스트용 가족 코드 미리 만들어 놓고 그 코드 적기 — 또는 "새 가족 시작" 안내
- [ ] 마이크 권한 안내 (실제 울음 없어도 잡음으로 테스트 가능)
- [ ] 음성 비전송 명시 (한 번 더)
- [ ] 연락 정보 (이름/전화/이메일)

## 마지막 — 제출 전 마음의 준비

- [ ] **수동 출시** 옵션 선택 (심사 통과 후 본인이 누를 때까지 대기)
- [ ] 첫 심사는 거절될 수도 있음 — 마음 비우기
- [ ] 가장 흔한 거절 사유:
  - 마이크 권한 사유 부족 → 우리는 "기기 외 미전송" 명시했으니 OK
  - 빈 페이지 / placeholder → 우리 앱엔 없음
  - 의료 조언 단정 → "참고용" 카피 있음 [`디자인/카피가이드.md`](../디자인/카피가이드.md)
  - 개인정보처리방침 누락 / 접근 불가 → 우리는 GitHub Pages 호스팅 예정
