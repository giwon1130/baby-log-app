## 1. 수집하는 개인정보 항목

### 1-1. 자동 수집 정보
- **가족 식별자(familyId)**: 자체 발급 UUID. Apple ID 등 외부 계정과 연결되지 않음
- **사용 로그**: API 호출 시각, 응답 코드 (서비스 안정성 모니터링)

### 1-2. 사용자가 직접 입력하는 정보
- **아기 정보**: 이름(닉네임 가능), 생년월일, 성별, 출생 체중·키
- **육아 기록**: 수유, 기저귀, 수면, 성장 측정값, 메모
- **울음 분석 메타데이터**: 녹음 시각, 추출된 음향 특성값(피치/음량 등 숫자)

### 1-3. 본 앱이 **수집하지 않는** 정보
- ❌ 음성/오디오 파일 — 기기에서도 저장하지 않으며 외부로 전송하지 않습니다
- ❌ 사진/이미지
- ❌ 위치 정보
- ❌ 광고 식별자(IDFA) 등 추적 식별자
- ❌ 연락처, 사진, 캘린더 등 시스템 데이터
- ❌ Apple ID, 이메일, 전화번호

## 7. 음성 데이터 처리에 대한 특별 고지

울음 분석 기능은 다음과 같이 동작합니다:

1. 사용자가 "분석 시작" 버튼을 누르면 5초간 마이크 입력을 받습니다
2. **iOS 디바이스 내부에서** Apple의 SoundAnalysis 프레임워크로 울음 여부를 판단하고,
   별도 알고리즘으로 음향 특성값(피치, 음량, 리듬 등)을 추출합니다
3. **5초 후 메모리 버퍼는 즉시 해제됩니다.** 음성 파일은 디스크에 저장되지 않습니다.
4. 서버로 전송되는 데이터는 위 2단계에서 추출된 **숫자 값** 뿐입니다
5. 서버는 이 숫자 값과 사용자의 과거 라벨 데이터를 종합해 추정 결과를 반환합니다

따라서 사용자의 음성/대화 내용이 외부로 노출되거나 저장될 가능성은 없습니다.
