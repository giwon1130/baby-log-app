## 설명 (Description) — 4000자 이내
```
베이비로그는 신생아 부모를 위해 만들어진 기록 + AI 분석 앱입니다.

■ 주요 기능

【통합 기록】
• 수유 — 모유/분유/혼합, 양(ml) 또는 좌우 시간(분)
• 기저귀 — WET / DIRTY / MIXED / DRY
• 수면 — 시작/종료 토글, 진행 중 표시
• 성장 — 체중/키/머리둘레 측정 시계열

【가족 공유】
8자리 초대 코드로 부부 / 시댁 / 친정 어디서나 같은 기록을 봅니다.
한 명이 입력하면 다른 가족도 즉시 확인.

【AI 울음 분석】
• 5초 녹음 → 어떤 이유로 우는지 추정
• 6가지 라벨: 배고픔 / 졸림 / 불편함 / 트림 / 통증 / 모르겠음
• 음성은 절대 기기를 떠나지 않습니다 (숫자 특성값만 분석)
• 사용자가 정답을 알려주면 우리 아기에 맞춰 점점 정확해져요

【통계】
• 오늘 요약 — 수유 횟수, 총량, 기저귀, 수면
• 주간 차트
• 다음 수유 시간 자동 알림

■ 프라이버시 우선

• 음성 파일은 어디에도 저장되지 않습니다
• 수집되는 건 숫자 특성값(피치, 음량 등)만
• 광고 추적 없음
• 제3자 데이터 공유 없음

■ 안내

이 앱의 울음 분석은 참고 정보이며 의학적 진단을 대체하지 않습니다.
아기의 건강에 우려가 있으면 반드시 소아과 전문의와 상담하세요.
```
