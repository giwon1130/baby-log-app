## 6. 스크린샷 캡처 가이드

본인 iPhone에서 다음 6 화면을 만든 다음 **전원 + 볼륨 위** 동시 누르기.

각 화면 미리 데이터 채워두면 풍부해 보임:
- 가족 1개 + 아기 1개
- 수유 기록 3~5건
- 기저귀 기록 3~5건
- 수면 기록 1~2건 (1건은 진행 중)
- 울음 분석 1~2건

| # | 화면 | 강조 포인트 |
|---|------|-----------|
| 1 | 홈 (`HomeScreen`) | 빠른 기록 토글, "다음 수유 시각", 오늘 요약 |
| 2 | 기록 → 수유 | 수유 입력 모달 또는 리스트 |
| 3 | 통계 → 주간 | 막대 차트 |
| 4 | 울음분석 → 결과 화면 | **분석 디테일** 카드가 보이게 |
| 5 | 울음분석 → 분석 기록 | 학습 단계 배너 + 통계 카드 |
| 6 | 아기 → 가족 초대 코드 | 코드 카드 |

캡처 후 사진 앱에서 확인 → ASC 6.7" 박스에 드래그 앤 드롭.
