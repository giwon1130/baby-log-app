## 주요 변경 이력

### 2026-06
- **패턴 기반 로컬 알림** — `feedingPattern.ts` 신설. 수유/기저귀 기록 간격, 낮잠은 깨어있는 시간(awake window)의 **중앙값**으로 개인화 알림. 표본 부족 시 기존 고정값 폴백. 설정에 "자동" 칩 추가.
- **다중 아기 홈 빠른 전환** — `BabySwitcherSheet` 바텀시트. 홈 아기 카드 "전환 ▾" 으로 즉시 전환.
- **홈 위젯 강화** — systemLarge 위젯 추가, widgetURL 딥링크(`babylog://log/feed|diaper|sleep`), 마지막 기저귀·수면 시각 표시. 앱 스킴 `babylog` + React Navigation linking 구성.
- **데이터 export** — `exportData.ts` 신설. 수유/기저귀/수면/성장 전체를 CSV(엑셀·BOM)·JSON으로 내보내 공유(expo-file-system+sharing). 아기 프로필에 카드 추가. `expo-file-system ~19.0.21` 의존성 추가.
- **에러 처리 일관성** — Cry 화면(Monitor/History)의 에러 경로 `Alert` → `ErrorBanner`/`useErrorRetry` 인라인 패턴으로 통일(재시도 포함). 성공 Alert·확인 대화상자는 유지.

### 2026-04
- 울음 분석 결과에 **분석 디테일** 섹션 추가 (피치/리듬/음량 시각화)
- **CryHistoryScreen** 추가 — 과거 분석 + 통계 + 정정
- CryMonitorScreen 컴포넌트 분리 (595줄 → 287줄)
- 백엔드 음향 feature 6개 컬럼 추가 (`bl_cry_samples` ALTER)
- HUNGER 라벨 편향 버그 수정 (시간 기반 prior 가중치 조정)
- 음향 규칙 추가: 피치 > 600Hz → PAIN, 리듬성 > 0.45 → HUNGER
- 두 레포 README 갱신 + AGENTS.md 신설
- Railway 배포 자동화 확인
